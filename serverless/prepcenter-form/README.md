# Преп-Центр: форма обратной связи и доставка заявок через Yandex Cloud

Схема: **prep-center.ru (GitHub Pages) → Cloud Functions → Cloud Postbox → info@prep-center.ru и ya@gaeo.ru**.

**Текущее состояние (10.11.2026):** публичная функция `prepcenter-form` создана и подключена в `assets/prep-form-config.js` (`https://functions.yandexcloud.net/d4emtgdns8k5tca7p9re`). Письмо с тестовой заявкой получено на `info@prep-center.ru` (подтверждено владельцем сайта); получение того же письма на `ya@gaeo.ru` в этой переписке отдельно не подтверждено. Функция допускает два адреса в `POSTBOX_TO`. Ниже сохранена инструкция для повторной настройки. Публичный URL функции не является секретом.

## Реализация на сайте

- `assets/prep-lead-form.css`: стили в палитре Преп-Центра, мобильная верстка.
- `assets/prep-lead-form.js`: единая форма для встроенных блоков и модальных окон; по умолчанию 🇷🇺 Россия, +7, с выбором других стран и маской телефона. Подключается из общего `assets/shared-components.js`.
- `assets/prep-form-config.js`: единственный публичный адрес обработчика.
- `serverless/prepcenter-form/index.py`: серверная часть на Python; секретов нет.

Старый снимок сайта `restoration/source/home-20260822.html` содержит 4 формы: одна была встроена в пятишаговый калькулятор (в восстановленной версии калькулятор уже работает и может открыть общую форму с готовым расчетом), две открытых формы после отзывов и после FAQ, и одно общее модальное окно. Кнопки **«Начать сотрудничество»**, **«Записаться на экскурсию»** и **«Оставить заявку»** в историческом HTML ссылались на `#modal`. Кнопка **«Рассчитать стоимость»** ссылалась на `#calc` и не должна быть переключена на новую форму. Явные ссылки «Telegram» сохраняются.

На восстановленной главной форма автоматически выводится перед разделом «О компании» (сразу после отзывов) и после блока «Вопросы и ответы». На странице `/contacts/` добавлена открытая форма. Кнопки с названиями формы открывают общее модальное окно на всех страницах.

## Этап 1: вход и создание каталога Яндекс Cloud

1. Открыть https://console.yandex.cloud/ и войти именно под Яндекс ID `info@prep-center.ru`.
2. Выбрать существующее облако/каталог Преп-Центра либо создать новый. Для платных услуг потребуется подключенный платежный аккаунт. Проверить тариф и лимиты перед использованием.
3. Все дальнейшие ресурсы (сервисный аккаунт, Postbox и функция) создавать **в одном каталоге**.

## Этап 2: Cloud Postbox и подтверждение домена

1. Перейти в **Cloud Postbox → Создать адрес**, указать домен `prep-center.ru`, вариант **Простая настройка (Easy DKIM)**.
2. После создания получить **две CNAME-записи**, которые Postbox сформирует для этого конкретного домена.
3. В панели REG.RU для домена `prep-center.ru` выбрать управление DNS-зоной (делегирование `ns1.reg.ru`/`ns2.reg.ru` сохранить). Добавить **ровно эти две CNAME-записи**, точно скопировав имена/значения из Postbox. В REG.RU интерфейс может автоматически дописывать `.prep-center.ru`: не создавать имя с двойным суффиксом.
4. **Не менять A, AAAA, CNAME www, NS и MX сайта/почты.** SPF и DMARC осмотреть отдельно: для Postbox рекомендован `include:spf.postbox.yandexcloud.net`. SPF у одного домена должен быть одним TXT со строкой `v=spf1...`; существующую запись почты нужно объединять с новой по действующим правилам, не создавать второй `v=spf1`. При существующей DMARC не перезаписывать без анализа.
5. Вернуться в Cloud Postbox, убедиться в статусе проверки домена **Success**. Значения DNS для DKIM нельзя выдумывать заранее.

## Этап 3: сервисный аккаунт и Cloud Functions

1. В том же каталоге создать сервисный аккаунт **prepcenter-form-sender** и назначить ему роль **postbox.sender** на каталог.
2. Cloud Functions → Создать функцию, имя **prepcenter-form**.
3. Создать версию: **Python 3.12**, исходный файл `index.py` из этой папки, точка входа `index.handler`, память **128 МБ**, таймаут **10 секунд**, сервисный аккаунт **prepcenter-form-sender**. Внешние Python-библиотеки не нужны.
4. Переменные окружения (без кавычек):

```text
POSTBOX_FROM=form@prep-center.ru
POSTBOX_TO=info@prep-center.ru,ya@gaeo.ru
ALLOWED_ORIGINS=https://prep-center.ru,https://www.prep-center.ru
MAX_BODY_BYTES=32768
MIN_FILL_SECONDS=1.5
```

5. Для отправки одной заявки сразу на 2 адреса укажите их в `POSTBOX_TO` **через запятую без пробелов**. Обработчик строит MIME-заголовок `To` и массив `Destination.ToAddresses` из списка, удаляет повторы и отклоняет неверные адреса. Первые письма получают напрямую `info@prep-center.ru` и `ya@gaeo.ru`, редирект Яндекс 360 не нужен. Для изменения списка потребуется обновить переменную в новой версии Cloud Functions.
6. Сохранить версию, включить опцию **«Публичная функция»** в обзоре.
6. Скопировать фактический HTTPS-адрес вида `https://functions.yandexcloud.net/<ID>`. Без адреса из реальной консоли значение в конфиге не заполнять. **Не копировать чужую функцию GAEO/IR.**

Документация:
- https://yandex.cloud/ru/docs/functions/operations/function/function-create
- https://yandex.cloud/ru/docs/functions/quickstart/create-function/python-function-quickstart
- https://yandex.cloud/ru/docs/functions/operations/function/function-public
- https://yandex.cloud/ru/docs/functions/lang/python/context

## Этап 4: включение доставки и тест

1. После успешной проверки DKIM и сохранения публичной функции заменить `''` в `assets/prep-form-config.js` на настоящий URL функции. Пример:

```js
window.PREP_CENTER_FORM_ENDPOINT = 'https://functions.yandexcloud.net/<РЕАЛЬНЫЙ-ID>';
```

2. Открыть публичный `https://prep-center.ru/` в новой сессии. Проверить обе встроенные формы, модальное окно, страницу `/contacts/`, кнопку экскурсии, верстку 390px и десктоп.
3. Сделать **одну тестовую заявку** с реальным именем, корректным телефоном +7 и способом связи, убедиться в HTTP 200 с `{"ok":true}`, затем **проверить письмо в обоих ящиках: `info@prep-center.ru` и `ya@gaeo.ru`**. Ответ 200 еще не доказывает доставку письма в ящик, поэтому нужны оба подтверждения и при необходимости журналы функции/Postbox.
4. Проверить отдельный сценарий email без телефона, длинный комментарий, CORS и отрицательную валидацию.
5. Проверить, что явные Telegram-ссылки по-прежнему открывают Telegram, а **«Рассчитать стоимость»** не стало вызывать форму: калькулятор уже восстановлен: этот пункт относится к первоначальному плану настройки; при приемке проверять, что «Рассчитать стоимость» открывает калькулятор, а «Отправить» на шаге 5 — форму с расчетом.
6. Не объявлять приемку завершенной, пока не проверены мобильный вид, получение настоящего письма и отсутствие дублей.

## Безопасность

Не добавлять API-ключи, IAM-токены, секреты отправки или пароль Яндекса в GitHub и браузерный код. Функция использует временный токен подключенного сервисного аккаунта из контекста исполнения. Сервер валидирует Origin, имя, телефон/email, допустимые способы связи, ограничивает размер данных, использует ловушку для ботов и фильтр слишком быстрых отправок; персональные данные заявок не выводятся в журналы.
