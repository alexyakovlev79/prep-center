- `index.html` и `assets/site.css`: статическая адаптивная страница с компактной шапкой, сетками услуг, примеров поставок, кейсов, видео и отзывов.

- Неработающие формы заменены контактными блоками. Данные посетителей не собираются.
- Публикация настроена из ветки `main`, каталога `/(root)`. Домен `prep-center.ru` привязан пользователем; 04.11.2026 идет переключение DNS.

## Сохраненные исходники

`restore-source.zip` содержит неизмененный октябрьский HTML, архивные стили и материалы первоначального восстановления. Текущий внешний вид задают читаемые HTML/CSS и файлы в `assets/`.

Это временное восстановление с переработанной версткой. Часть декоративной графики исходного сайта отсутствует в веб-архиве. Логотипы маркетплейсов не выдумывались: названия показаны текстом.

Временный `noindex, follow` сохранен до отдельной проверки запуска на основном домене. DNS изменил пользователь 04.11.2026; в моей среде домен пока недоступен.
