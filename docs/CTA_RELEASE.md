# Преп-Центр: единый стандарт CTA

Дата: 10.11.2026. Изменения согласованы в чате проекта.

## Правила

- Форма заявки: оранжевый фон `#ff9900`, темный текст.
- Telegram: на светлом фоне голубой `#229ed9` с белым текстом; на темном фоне белая кнопка с синим текстом и рамкой.
- Информационные переходы: почти белый фон, темная рамка; не маскируются под отправку заявки.
- Скругление CTA: 14 px, включая кнопку шапки. При наведении курсор pointer.
- Основной выбор: форма и Telegram. Калькулятор отдельным действием только на главной и в тарифах.
- На телефоне парные действия выстраиваются в столбик, не выходят за ширину экрана.
- Контекст страницы/блока передается в комментарий формы через `data-prep-request`; в Telegram используется тот же текст. Из шапки комментарий пустой; экскурсия сохраняет свой контекст.
- В кейсах призыв обсудить похожую задачу открывает форму, а не уводит на страницу услуги.
- Калькулятор: сохраняется точный расчет; сброс выполняется только после успешной отправки именно калькуляторной заявки. Обычная контекстная форма не сбрасывает калькулятор.

## Канонические файлы

`assets/cta.css`, `scripts/polish_cta.py`, `scripts/apply_cta_runtime.py`, компоненты в `components/`, обработчик формы `assets/prep-lead-form.js`.

Повторный запуск `python scripts/polish_cta.py` не создает дубли кнопок. Исторические HTML в `restoration/source/` не изменяются. При сборке общих компонентов нормализация вызывается из `scripts/build_components.py`.
